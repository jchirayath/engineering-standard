# Engineering Standard — v1.3 gap report

Researched 2026-10-09 against v1.2.0 (`4b3a494`). Draft proposal — nothing here is in the standard yet.

**Method.** Four parallel research passes (AI-agent development · web/Next.js/npm · mobile/Flutter/Supabase ·
regulation/supply chain/lifecycle), each given the existing rule set and asked only for gaps, with a primary
source per claim. Overlapping proposals are merged below. **Confidence:** ✅ primary source read ·
◐ secondary source only · ⚠ unverified or sources conflict. Several items post-date the model's training
data, so ◐/⚠ items must be checked before they become MUST rules.

## B · New section §2C — AI agents that build the code (AGT-)

The standard says how *code* must look; nothing yet governs how the *agent* is configured. These are the
rules most suited to the planned plugin's hooks.

| ID | Lvl | Rule | Enforce | Conf. |
|---|---|---|---|---|
| AGT-1 | MUST | Every repo ships `.claude/settings.json` denying `Read(./.env*)`, `Read(./secrets/**)`, `Read(//**/.ssh/**)` and setting `permissions.disableBypassPermissionsMode: "disable"`. Security limits never live only in CLAUDE.md — permission rules are enforced by the harness, prose is not. | CI check for required deny entries; plugin `SessionStart` warns | ✅ code.claude.com/docs/en/permissions |
| AGT-2 | MUST | Bash runs sandboxed with `failIfUnavailable: true` and `allowUnsandboxedCommands: false`, an explicit egress allow-list, and credential paths denied; `excludedCommands` never covers an interpreter or `docker`. | AGT-3 | MUST | `--dangerously-skip-permissions` / bypass mode only in a disposable container with no production credentials; repos that can reach production disable auto mode or set a managed default mode. | managed settings; grep outside devcontainer | ✅ (◐ the claim that auto mode is now the default) |
| AGT-4 | MUST | **No lethal trifecta:** no session or feature combines private data + untrusted content + an outbound channel; when untrusted content is in context, remove one leg (egress allow-list, deny `Bash(curl *)`, no rendering of model-emitted URLs/images). | threat-model field per tool-using feature; injection-fixture test asserting no outbound call | ✅ Willison 2025-06 |
| AGT-5 | MUST | MCP servers and plugins are dependencies: allow-listed by command/URL, stdio packages pinned to an exact version (never bare `npx -y pkg`), tool descriptions re-reviewed when they change (rug-pull / tool poisoning). | `.mcp.json` lint; managed `allowedMcpServers`; description-hash check | ✅ docs / ◐ poisoning details |

| AGT-7 | MUST | Every project subagent declares a `tools:` allow-list; review/research agents are read-only with no MCP tools (omitted `tools` inherits everything). | lint `.claude/agents/*.md` | ✅ |
