# v1.4 candidates — what the most-used Claude skills have that the standard doesn't

Scanned 2026-10-09: the top ~35 Claude Code skills/plugins by installs and stars, all 315 entries in Anthropic's
[official plugin marketplace](https://github.com/anthropics/claude-plugins-official), and ~45 skills read in full
(SKILL.md / agent prompts). Each was checked against the standard (v1.3, 352 rules). Read-only — nothing was installed
or run; fetched content was treated as untrusted data. **Nothing here is in the standard yet**: each candidate goes
through `/engineering-standard:consume` once chosen.

**Popularity signals** (as of 2026-10-09; not comparable across sites): claude.com/plugins install counts (two spot-checked,
the rest from a 2026-09-26 snapshot), [skills.sh](https://skills.sh) per-skill installs, GitHub stars (attention, not use —
several repos grew implausibly fast). Most of the top entries' ideas are **already covered** — superpowers, grill-me, tdd,
ponytail, caveman, frontend-design, code-review, code-simplifier, silent-failure-hunter, pr-test-analyzer, find-bugs,
doubt-driven review and security-guidance map onto AGT-11…16, TEST-*, COR-*, APP_REVIEW and the plugin's hooks.

## Fixed immediately (a bug in existing enforcement)

The AGT-8 test-loosening guard missed `pytest.skip()` inside a test, `self.skipTest`, `@pytest.mark.skipif`, `test.fail`,
`test.describe.fixme/only`, `it.todo` / `test.todo` and `@Ignore` — the forms Playwright's own healer agent uses ("mark this
test as test.fixme()"). Widened in `lib/guards.mjs`, with regression tests.

**Also worth a SHOULD:** version-grounded framework code (cite the official docs for the pinned version — addyosmani
source-driven, Context7) · spec carries a measurable success metric and Given/When/Then criteria mapped to tests (PM
skills) · Terraform lockfile + remote encrypted state + `terraform test` (HashiCorp) · analytics event registry with
`object_action` names and no PII (marketingskills) · no customer names/PII in commits and PR bodies; agent PRs open as drafts
(Sentry) · monthly report of the agent's own token spend and context budget (session-report, context-budget) · unbounded
agent loops need an iteration cap (ralph-loop) · a correction made twice becomes a hook (hookify) · comment-based finding
exclusions use the ENF-2 format (security-guidance) · review findings as SARIF with stable IDs and a coverage section
(claude-security) · prompt-cache hit rate as an LLM cost metric (claude-api).

## Companions worth pinning (vendor-maintained, prompt-only)

`supabase/agent-skills` → supabase · `firebase/agent-skills` → firebase-security-rules-auditor · `stripe/ai` →
stripe-best-practices (its `npm i -g` falls under NPM-1) · `vercel-labs/agent-skills` → react-best-practices (already
installed via the Vercel plugin). Each would get a precedence note like frontend-design's (THEME-12).

## Not recommended (as installed)

- `GoogleChrome/modern-web-guidance` runs `npx -y …@latest` on every frontend task; Vercel `web-design-guidelines` and
  `writing-guidelines` fetch rules from `main` on every run — unpinned code/instructions (AGT-5, NPM-1). Distil instead.
- Anthropic `theme-factory` / `brand-guidelines` and ibelick `baseline-ui` impose palettes or Tailwind defaults (THEME-1/8).
- Anthropic `webapp-testing` tells the agent not to read helper source before running it and to wait on `networkidle`.
- Anthropic `docx`/`xlsx`/`pdf`/`pptx` are licensed "Proprietary" — use as tools, never copy their text in.
- Memory/compaction plugins that sync transcripts to third parties (AGT-4, AGT-9).
